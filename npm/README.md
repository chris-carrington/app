## What is the purpose of this `npm` folder?
- Hold code that we feel may one day be public npm packages


## What are the prerequisites to being a folder w/in `npm`?
- No business logic
- Includes tools that we feel others would appreciate


## What are the prerequisites to publishing on `npm`?
- 100% test code coverage
- An `index` file that exports all public things
- All public things have helpful `jsdoc` comments that are maintained post minification
- A way to jump from `.d.ts` types to `src` code (maybe use `@see`)
- We've used it for at least a couple months (gives us time to fine tune its value)
